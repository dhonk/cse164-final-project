# CSE 164 Project - Recapping Project Spec from Kaggle:
Build a computer vision system for image-level classification and pixel-level semantic segmentation. In this project, you are given image-level labels, segmentation masks, unlabeled images, and a public validation set. For each hidden test image, your system must predict both:
1. an image-level class label
2. a pixel-level semantic segmentation mask

Main challenge is **semantic segmentation**. Final system should learn from limited labeled data, and make effective use of provided unlabeled data.

**Pretrained model weights not allowed.**

## The Data:
- Target classes: 300
- Image level labeled training images: 7,500 (classification task)
- Segmentation label training images: 3,000 (semantic segmentation task)
- Unlabeled training images: 50,000
- Public validation images: 750
- Hidden test images: 3,000

Labels are integer class_id values in **range 0 - 299.** \
For **semantic segmentation:** these are shifted, where
- 0: background or non target category
- 1-300: foreground classes
- 1000: ignore region

For foreground classes: **segmentation_id = class_id + 1** 

Important detail on the **1000: ignore region** comment: 1000 is used in ground truth masks as ignore regions. These pixels should not be scored. That means that when calculating loss later on, on pixels where the label 1000 appears, these should not be used in gradient calculation/loss.

## Kaggle Submission Format:
a csv as the following example:
```
image, class_id, segmentation_rle
test_00000.JPEG,17,1 20 18 300 15 18
test_00001.JPEG,3,0
```

segmentation_rle is **row-major, 1-indexed Run Length  Encoding triples** ->
```
start length value start length value
```
segmentation_rle only cares about foreground classes, runs of background/0 can be omitted. **HOWEVER** in the case of only background, the segmentation_rle column will contain just 0 *(see line 3 of the example submission)*.

## Evaluation
Score breakdown is based on
```
70% segmentation + 20% classification + 10% external
```
The external score is based on writeup material, and cannot be optimized for by the model.
### Segementation
Segmentation score is broken into the following:
- 70% mean IoU
- 20% boundary F-score
- 10% rare-class mIoU
### Classification
Based on macro-accuracy - means that the accuracy of each individual class is averaged.

2. pseudo labeling high confidence unlabeled images

4. boundary aware losses / post processing
